# 05 - ヒープ 優先度キュー 操作 デモ

**ビルド日**: 2026-11-02
**カテゴリ**: practical
**slug**: heapify-priority-queue-ops

## 概要

最小ヒープ・最大ヒープの操作をツリー形式で可視化するSPA。挿入・取出し・構築のアニメーション付き。

## 機能

- 最小ヒープ / 最大ヒープの切り替え
- 数値挿入（Bubble-up アニメーション）
- 根の取り出し（Heapify-down アニメーション）
- 配列からのヒープ構築（カンマ区切り入力）
- Canvas上でツリー描画（ノードハイライト）
- 配列表現のリアルタイム更新
- 操作ログ表示（最新30件）

## 技術仕様

- 単一HTMLファイル、Tailwind CDN使用
- Canvas 2D APIで動的ツリー配置・描画
- 400msインターバルのステップアニメーション
